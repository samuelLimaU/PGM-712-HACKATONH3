# Proyecto: Midnight Rider Clone (3D)

## Requisitos
- [X] Objeto 3D que se mueva SOLO con el mouse.
- [X] Arena con obstáculos generados de forma aleatoria (estilo Midnight Motorist FNAF6).
- [X] Contador de colisiones con los obstáculos.
- [X] Controlador de colisiones.
- [X] Controlador de tiempo de punto A a punto B.
