# Proyecto: Midnight Rider Clone (3D)

## Requisitos
- [ ] Objeto 3D que se mueva SOLO con el mouse.
- [ ] Arena con obstáculos generados de forma aleatoria (estilo Midnight Motorist FNAF6).
- [ ] Contador de colisiones con los obstáculos.
- [ ] Controlador de colisiones.
- [ ] Controlador de tiempo de punto A a punto B.
